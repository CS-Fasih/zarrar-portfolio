# IMMERSIVE VR EDUCATIONAL PLATFORM
**Final Year Project - Dawood University of Engineering & Technology**
**Role:** Lead Developer (Zarrar Abbas)
**Co-Developers:** Syed Zohair Raza, Nikhil Kumar
**Supervisor:** Dr. Syed Ali Asgher

## OVERVIEW
Developed a comprehensive, Meta Quest Pro-compatible Virtual Reality ecosystem comprising 12 distinct educational modules for Computer Science and Engineering students. The platform leverages 3D spatial computing to visualize abstract concepts, algorithms, and architectures, transforming traditional learning into an interactive, gamified, and immersive experience. 

A core feature across all modules is "Sage"—a context-aware, voice-activated AI teaching assistant powered by the Google Gemini API. Sage guides students, answers syllabus-specific questions in real-time, and uses animated gestures and lip-syncing to create a human-like tutoring presence.

## TECHNOLOGY STACK
- **Engine & Framework:** Vizard 8 (Python-based VR Engine)
- **Hardware:** Meta Quest Pro (OpenVR / VizConnect integration)
- **Programming Language:** Python
- **Analytics:** SightLab VR Pro (Eye-tracking and user data collection)
- **Artificial Intelligence:** Google Gemini API (LLM for conversational tutoring)
- **Speech Tech:** PyTTSx3 / PiperTTS (Text-to-Speech), SpeechRecognition (Speech-to-Text)
- **3D Assets:** Custom .osgb models, procedural shapes (vizshape), UI/HUD Canvas

## 🚀 PROJECTS / MODULES LIST 

### 1. Design & Analysis of Algorithms (DAA)
*Visualizing sorting, structures, and pathfinding in 3D.*
- **Selection Sort:** Students physically watch 3D representations of arrays sort themselves step-by-step, observing the logic of comparative sorting in real-time.
- **Dijkstra's Shortest Path:** A spatial graph visualization where nodes and edges calculate the shortest path dynamically, allowing students to visually trace algorithmic decision-making.

### 2. Data Structure Algorithms (DSA)
*Interactive manipulation of data containers.*
- **Linked List Station:** A fully interactive 3D laboratory where students insert physical node blocks, use VR controllers to draw connection arrows (pointers) between them, and trigger real-time traversal and deletion drop-animations.
- **Advanced Operations:** Watch dynamic physical rearrangements of nodes during Sorting operations, and observe linear data structurally transform into Binary Trees in mid-air.

### 3. Artificial Intelligence (AI)
*Demystifying machine learning logic through spatial data representation.*
- **Neural Network:** Visualizes the hidden layers and weight adjustments of a network solving the XOR problem, showing how data transforms as it passes through physical nodes.
- **K-Nearest Neighbors (KNN):** Immerses the user inside a 3D scatter plot of data points, visually demonstrating how proximity determines classification.
- **Decision Trees:** Explores massive 3D branching structures, allowing students to walk through the data splitting logic at each node.

### 4. Object-Oriented Programming (OOP)
*Gamified labs where OOP concepts are physical objects.*
- **Encapsulation Heist:** A gamified experience demonstrating data hiding and access modifiers (Public, Private, Protected) through physical barriers and locked data vaults.
- **Inheritance Factory:** Visualizes class hierarchies by showing physical traits and behaviors being passed down from parent to child objects on a virtual factory line.
- **Polymorphism Arena & Abstraction:** Demonstrates method overriding and interface contracts by showing how different objects physically respond to the same commands.

### 5. Programming Fundamentals (PF)
*A foundational "Code Quest" for logic building.*
- **Variable Warehouse:** An interactive sorting game where students must physically grab and assign correct data types (int, float, string) to physical storage crates.
- **Loop Arena & Recursion Tower:** Visualizes code execution loops and visually stacks "function calls" into a towering physical call stack that unwinds during factorial calculation.
- **Function Factory:** Students insert physical input parameters into a 3D machine to watch the logic process and spit out the computed output.

### 6. Operating Systems (OS)
*Comprehensive visualization of core OS logic.*
- **CPU & Disk Scheduling:** Transforms abstract scheduling algorithms (FCFS, SJF, Round Robin, SCAN) into interactive 3D Gantt charts and moving disk heads, allowing students to compare algorithmic efficiency.
- **Process Synchronization (Dining Philosophers):** A 3D simulation of the classic Dining Philosophers problem, visually demonstrating deadlocks, resource starvation, and Banker's Algorithm safety states.

### 7. Computer Organization & Assembly Language (COAL)
*A micro-level view of hardware architecture.*
- **CPU Pipeline:** Shrinks the user inside a processor to watch the step-by-step 3D execution cycles (Fetch, Decode, Execute, Memory, Writeback), illustrating how assembly instructions flow through hardware registers.

### 8. Database Management System (DBMS)
*Abstracting data processing.*
- **SQL Query Processing:** Visualizes database tables as floating 3D grids, showing exactly how SQL queries execute, join tables, and filter physical data rows in real-time.

### 9. Applied Physics (AP)
*Bringing theoretical physics to life in a laboratory sandbox.*
- **Electromagnetism & Mechanics:** Allows students to manipulate variables in Coulomb's Law and Projectile Motion, visually observing the resulting changes in 3D electric fields, physical trajectories, and Capacitor fields.

### 10. Basic Electronics
*A virtual workbench for circuit prototyping and microscopic physical phenomena.*
- **PN Junction (Atomic Level):** Shrinks the user to a microscopic scale to observe the flow of electrons and holes across the depletion region in real-time, visually demonstrating forward and reverse bias at the atomic level.
- **Series & Parallel Circuit Builder:** An interactive, hands-on activity where students physically grab electronic components (resistors, batteries, wires) using VR hand controllers and snap them onto a glowing 3D blueprint to construct working circuits and observe real-time voltage/current changes.
- **Ohm's Law:** Interactive demonstration of the relationship between voltage, current, and resistance.

### 11. Digital Logic Designing (DLD)
*Gate-level circuit simulation.*
- **Interactive Logic Gates:** Students physically connect inputs to massive 3D logic gates (AND, OR, NOT, XOR) and Flip-Flops (SR, JK, D, T) to observe instantaneous changes in truth tables and output signals.

### 12. Data Communication & Network (DCN)
*Visualizing secure networking concepts.*
- **Encryption/Decryption Visualization:** A step-by-step interactive station demonstrating cryptographic processes, showing how plain text is visually scrambled into cipher text and safely transmitted across a network.

## 🌟 KEY TECHNICAL ACHIEVEMENTS FOR PORTFOLIO
- **Multithreaded AI Architecture:** Engineered a non-blocking voice recognition and TTS pipeline in Python, allowing seamless conversational learning without freezing the VR rendering thread.
- **Procedural 3D UI:** Developed a custom HUD and spatial UI framework using Vizard, ensuring menus and text remain legible and accessible from any viewpoint in VR.
- **Robust Exception Handling:** Implemented resilient asset loading systems (wrapping `.osgb` loading in try/except blocks) to prevent application crashes on Meta Quest standalone hardware.
- **Eye-Tracking Integration:** Utilized SightLab SDK to map gaze analytics, determining where students focus when learning abstract algorithms.
- **Software IPD Scaling:** Manipulated Virtual Inter-Pupillary Distance to create dynamic user-scaling, ensuring the player feels appropriately sized across massively different environment scales (from micro-circuits to massive warehouses).
